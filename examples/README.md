# Examples

## Canonical V1 examples

These files are validated in CI against `schemas/entity-manifest.v1.schema.json`:

- `minimal.json`
- `local-business.json`
- `association.json`
- `public-entity.json`

## Experimental examples

`experimental/` contains legacy or exploratory examples, including extension-oriented shapes (for example hub files).

They are intentionally not part of the canonical V1 validation set.
