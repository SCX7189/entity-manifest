# Changelog

## [1.0.0-rc1] - 2026-02-25

### Added

- Normative v1.0 specification with explicit field contract and compatibility policy.
- JSON Schema (`draft 2020-12`) for `entity-manifest/1.0`.
- Node-based validation tooling using Ajv.
- GitHub Actions workflow for schema and canonical example validation.
- Canonical V1 examples and usage documentation.
- OSS governance files: CONTRIBUTING, CODE_OF_CONDUCT, SECURITY, ROADMAP, LICENSE.

### Changed

- README rewritten for clear V1 positioning and quickstart.
- Legacy and extension-oriented examples moved under `examples/experimental/`.
- Hub model moved to extension documentation (`extensions/hub.md`).
